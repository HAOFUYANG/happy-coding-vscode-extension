# 测试策略

## 测试概述

Happy Coding VSCode Extension 采用多层次的测试策略，确保代码质量和功能稳定性。测试覆盖单元测试、集成测试、端到端测试和性能测试等多个维度。

## 测试架构

### 测试金字塔

```
        /\
       /  \
      / E2E \     端到端测试 (少量)
     /______\
    /        \
   /Integration\ 集成测试 (适量)
  /__________\
 /            \
/  Unit Tests  \   单元测试 (大量)
/______________\
```

### 测试分层策略

#### 1. 单元测试 (70%)
- **范围**: 独立的函数、类和组件
- **工具**: Jest, React Testing Library
- **特点**: 快速、隔离、可重复

#### 2. 集成测试 (20%)
- **范围**: 模块间交互、API 集成
- **工具**: Jest, Supertest
- **特点**: 验证组件协作

#### 3. 端到端测试 (10%)
- **范围**: 完整用户流程
- **工具**: Playwright
- **特点**: 真实环境验证

// test/performance/performance.test.ts
import { test, expect } from '@playwright/test';

test.describe('Performance Tests', () => {
  test('page load performance', async ({ page }) => {
    // 开始性能监控
    await page.goto('/', { waitUntil: 'networkidle' });
    
    // 获取性能指标
    const performanceMetrics = await page.evaluate(() => {
      const navigation = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming;
      return {
        domContentLoaded: navigation.domContentLoadedEventEnd - navigation.domContentLoadedEventStart,
        loadComplete: navigation.loadEventEnd - navigation.loadEventStart,
        firstPaint: performance.getEntriesByType('paint').find(entry => entry.name === 'first-paint')?.startTime,
        firstContentfulPaint: performance.getEntriesByType('paint').find(entry => entry.name === 'first-contentful-paint')?.startTime,
      };
    });
    
    // 验证性能指标
    expect(performanceMetrics.domContentLoaded).toBeLessThan(1000); // 1秒内
    expect(performanceMetrics.firstContentfulPaint).toBeLessThan(2000); // 2秒内
  });
  
  test('memory usage', async ({ page }) => {
    await page.goto('/');
    
    // 执行一些操作来测试内存使用
    for (let i = 0; i < 10; i++) {
      await page.click('text=脚手架');
      await page.click('text=小工具');
      await page.waitForTimeout(100);
    }
    
    // 检查内存使用情况
    const memoryInfo = await page.evaluate(() => {
      return (performance as any).memory ? {
        usedJSHeapSize: (performance as any).memory.usedJSHeapSize,
        totalJSHeapSize: (performance as any).memory.totalJSHeapSize,
        jsHeapSizeLimit: (performance as any).memory.jsHeapSizeLimit,
      } : null;
    });

name: Test Suite

on:
  push:
    branches: [ main, develop ]

    branches: [ main ]

      uses: actions/setup-node@v3
      with:
        node-version: ${{ matrix.node-version }}
        cache: 'npm'
    
    - name: Install dependencies
      run: |
        npm ci
        cd webview-side-bar && npm ci
    
    - name: Run unit tests
      run: npm run test:unit
    
    - name: Run frontend tests
      run: cd webview-side-bar && npm test
    
    - name: Upload coverage
      uses: codecov/codecov-action@v3
      with:
        file: ./coverage/lcov.info
  
  integration-tests:
    runs-on: ubuntu-latest
    needs: unit-tests
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18.x'
        cache: 'npm'
    
    - name: Install dependencies
      run: npm ci
    
    - name: Run integration tests
      run: npm run test:integration
  
  e2e-tests:
    runs-on: ubuntu-latest
    needs: unit-tests
    
    steps:
    - uses: actions/checkout@v3

        cache: 'npm'
    
    - name: Install dependencies
      run: |
        npm ci
        cd webview-side-bar && npm ci
    
    - name: Install Playwright
      run: npx playwright install --with-deps
    
    - name: Run E2E tests
      run: npm run test:e2e
    
    - name: Upload test results

      if: always()
