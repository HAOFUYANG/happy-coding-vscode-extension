## 1. 智能代码生成模块

### 模块概述
智能代码生成模块是扩展的核心功能之一，基于 VSCode 的 InlineSuggest API 实现自动化代码生成和智能采纳机制。

### 核心特性

#### 🤖 自动代码生成
- **触发机制**: 自动触发 VSCode 的内联建议功能
- **循环生成**: 持续的代码生成循环，直到达到设定条件
- **智能触发**: 在适当的时机插入触发词以获得更好的建议

#### 📊 智能采纳策略
```typescript
// 采纳决策算法
const currentLineCount = editor.document.lineCount;
const generatedRatio = this.acceptedCount / currentLineCount;
const shouldAccept = Math.random() < this.acceptRatio / 100 - generatedRatio;
```

#### 📈 实时监控
- **生成统计**: 实时统计生成的代码行数和采纳次数
- **内容记录**: 详细记录每次采纳的内容和上下文
- **进度跟踪**: 显示生成进度和剩余目标

### 技术实现

## 2. 脚手架管理模块

### 模块概述
脚手架管理模块提供可视化的项目创建和模板管理功能，集成了 Happy CLI 工具链。

### 核心特性

#### 🔍 环境检测
- **Node.js 版本检查**: 确保 Node.js 环境满足要求
- **CLI 工具检测**: 检查 Happy CLI 是否已安装
- **依赖状态显示**: 在 UI 中显示环境状态

#### 🏗️ 项目创建
- **模板选择**: 支持多种项目模板类型
- **可视化配置**: 图形界面配置项目参数
- **自动化流程**: 自动完成下载、安装、配置流程

#### 📦 模板管理
- **模板缓存**: 本地缓存常用模板
- **版本管理**: 支持模板版本控制
- **自定义模板**: 支持用户自定义模板

### 技术实现

#### 核心类结构
```typescript
@controller("Cli")
export class CliController {
  // 订阅者管理
  private subscribers: ((data: any) => void)[] = [];
  
  // 主要方法
  @callable("checkEnvironment")     // 环境检查
  @callable("executeCli")          // 执行脚手架
  @callable("installHappyCli")     // 安装 CLI 工具
  @subscribable("processStepUpdate") // 进度更新
}
```

#### 工作流程

##### 1. 环境检查流程
```typescript

  const nodeVersionCheckResult = checkNodeVersion();
  const cliInstalled = checkHappyCliInstalled();

    nodeVersionCheckResult,
    cliInstalled
  };

```

##### 2. 项目创建流程
```typescript
@callable("executeCli")

  name: string;
  type: string;
  template: any;
}): Promise<any> {
  // Step 1: 选择目标文件夹
  const folder = await vscode.window.showOpenDialog({...});
  
  // Step 2: 创建模板配置
  const selectedTemplate = await createTemplateByOptions({...});
  
  // Step 3: 下载模板

  // Step 4: 安装模板
```

## 3. Git 操作模块

### 模块概述
Git 操作模块提供可视化的版本控制功能，简化常见的 Git 操作流程。

### 核心特性

#### 📋 仓库信息管理
- **远程仓库列表**: 获取并显示所有远程仓库
- **工作区状态**: 监控工作区文件变化
- **分支信息**: 显示当前分支状态

#### 🚀 快速操作
- **一键提交**: 自动执行 add、commit、push 流程
- **批量操作**: 支持批量文件操作
- **智能提交**: 自动生成提交信息格式

#### 🔄 实时监控
- **工作区监听**: 自动检测工作区变化
- **状态同步**: 实时同步 Git 状态到 UI

### 技术实现

#### 核心类结构
```typescript
@controller("Git")
export class GitController {
  constructor() {
    // 监听工作区变化
    vscode.workspace.onDidChangeWorkspaceFolders(() => {
      const cwd = vscode.workspace.workspaceFolders?.[0]?.uri.fsPath || "";
      this.projectChange({ cwd });
    });
  }
}
```

#### 主要功能

##### 获取远程仓库
```typescript
@callable("getRemotesWithPath")
async getRemotesWithPath(): Promise<{ remotes: string[]; cwd: string }> {
  const folder = vscode.workspace.workspaceFolders?.[0];
  const cwd = folder.uri.fsPath;
  
  return new Promise((resolve, reject) => {
    exec("git remote -v", { cwd }, (err, stdout) => {
      const remotes = stdout
        .split("\n")
        .map(line => line.split("\t")[0])
        .filter(Boolean);
      resolve({ remotes, cwd });
    });
  });
}
```

##### 提交和推送
```typescript
@callable("commitAndPush")
async commitAndPush(data: any): Promise<any> {
  const { selectedSst, commitMessage, remoteName } = data;
  const cwd = vscode.workspace.workspaceFolders?.[0].uri.fsPath;
  
  return new Promise((resolve, reject) => {
    exec(
      `git add . && git commit -m "${selectedSst} msg:${commitMessage}" && git push ${remoteName} HEAD`,
      { cwd },
      (err, stdout, stderr) => {
        resolve({ success: !err, err: err ? stdout : stderr });
      }
    );
  });
}
```

## 模块间通信

### 通信机制
所有模块都通过 CEC Client-Server 框架进行通信：

```typescript
// 控制器注册
registerControllers([
  GitController,
  AxiosController,
  UserController,
  CodingController,
  CliController,
  PlaywrightController,
]);

// 服务注册 (支持订阅)
registerServices([CodingController]);
```

### 数据流向
```
UI 组件 → CEC Client → Controller → Service → External API
       ← CEC Server ← Controller ← Service ← External API
```

### 事件订阅
```typescript
// 前端订阅
const { subscribe } = useCoding();
useEffect(() => {
  const unsubscribe = subscribe('generationUpdates', handleUpdate);
  return unsubscribe;
}, []);

// 后端发布
this.subscribers.forEach(cb => cb(data));
```
